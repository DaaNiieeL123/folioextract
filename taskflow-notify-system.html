Sistema de alertas — notify()

Una sola función decide dónde mostrar el mensaje: si le pasas un campo/formulario, sale en línea; si no, sale como isla dinámica. Revisa el código al final del archivo (o el script de abajo) para copiarlo tal cual a tu proyecto.

Confirmaciones rápidas → isla dinámica
notify({ type: 'success', text: '...' }) — sin target, cae en la isla.
Errores de formulario → en línea
notify({ type: 'error', text: '...', target: '#slot-id' }) — con target, sale pegado al campo.
Nombre de usuario
Contraseña
Uso general: notify({ type: 'success' | 'error' | 'warn', title, text, target, errorInput, duration }). Sin target → isla dinámica (con auto-cierre). Con target (un selector de un <div data-notify-slot>) → alerta en línea persistente hasta la siguiente acción.
